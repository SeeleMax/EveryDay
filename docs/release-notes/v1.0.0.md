# EveryDay v1.0.0

Windows 桌面每日计划软件的首个版本。**下载 `EveryDay.exe` 双击即用，目标机器无需安装 Python 或任何依赖。**

---

## 下载

| 文件 | 大小 | 说明 |
|---|---|---|
| `EveryDay.exe` | 81.1 MB | 自包含单文件程序，Windows 10 1809+ / Windows 11 |

首次启动会把自己解包到临时目录，因此比源码运行慢 1~3 秒。数据写在
`%LOCALAPPDATA%\EveryDay`，卸载时删掉该目录即可清理干净。

> 若系统缺少 Microsoft Visual C++ 2015-2022 Redistributable (x64)，
> 请先安装（绝大多数 Windows 已自带）。

---

## 功能

| 编号 | 功能 |
|---|---|
| F1 | 开机自启（写入当前用户注册表，无需管理员权限） |
| F2 | 桌面悬浮窗：无边框、半透明、始终置顶、不占任务栏，可拖动并记忆位置，跨屏失效时回退主屏 |
| F3 | 自定义任务：新建 / 编辑 / 删除，标题必填且 ≤100 字符 |
| F4 | 完成状态：勾选即持久化；**完成的任务不消失，而是整行半透明并沉到列表最下面** |
| F5 | 循环 / 单次：单次 / 每日 / 每周 / 每月，跨午夜自动重置 |
| F6 | 实时日历：读取本地 `.ics` 文件或 `http(s)` 订阅地址，展示今日日程 |
| F7 | 预设模板：内置 10 个模板，一键创建，支持增删改 |

其它：系统托盘、启动时数据库备份（保留 5 份）、按日滚动日志（保留 7 天）、
三层全局异常捕获、SQLite WAL 模式。

## 已知限制（诚实清单，完整版见仓库 docs/known-issues.md）

- **常驻内存约 129 MB**，未达需求文档写的 `<50MB`。该指标是按 WPF 假设写的，
  在 PySide6/Qt6 上不可达（框架基线即 36 MB）。
- ICS 的 `TZID` 被忽略，按本地时间解释；跨时区订阅可能偏移。
- 不支持 `BYDAY` / `BYSETPOS` 等高级递归规则；
  「每月第二个周二」这类会退化为只出现一次。
- 日历网络订阅在 UI 线程同步读取（15 秒超时），订阅不可达时可能短暂卡顿。
- **没有单实例互斥**：重复启动会出现多个托盘图标。
- 「每周 / 每月」任务的参考日期语义是推断的（复用 `due_date` 作锚点）。
- 每月 29/30/31 号的任务在短月**跳过而非顺延**。
- 取消完成状态时清空「完成日期」；单次任务只在完成当天保留，次日不再出现
  （需求文档原文要求完成后立即移除，本版按用户要求改为半透明下沉，
  见仓库 docs/acceptance-report.md §6.1）。

## 从源码构建

```powershell
git clone git@github.com:SeeleMax/EveryDay.git
cd EveryDay
& "C:\Users\<你>\AppData\Local\Programs\Python\Python313\python.exe" -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
python main.py
```

重新打包可执行程序：

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_exe.ps1
```

构建脚本会**在打包前净化 PATH**、**在打包后真的启动一次产物做自检**。
这两步都是踩坑换来的，细节见 `docs/known-issues.md` 的 PKG-01 ~ PKG-04。
