# EveryDay

每天一点积累 —— 学习记录、代码练习、踩坑笔记。

远程仓库：https://github.com/SeeleMax/EveryDay

## 目录结构

```
EveryDay/
├── README.md
├── .gitignore
└── 2026-10-15/
    └── note.md        # 每日笔记模板
```

建议按 `YYYY-MM-DD/` 建日期目录，当天所有练习代码和笔记都放进去。

## 每天怎么用

1. 复制一份 `2026-10-15/note.md` 到新日期目录，改名为当天日期
2. 当天写的代码直接放同一目录
3. PyCharm 里 `Ctrl+K` 提交，`Ctrl+Shift+K` 推送

## 提交信息建议

```
feat: 2026-10-15 学习记录
docs: 补充 xxx 笔记
fix: 修正 xxx 练习代码
```
